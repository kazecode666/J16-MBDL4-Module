# 样机待验证项目

首板 J1 已由用户焊接并插入 J16。用户报告（`USER_REPORTED`）已完成供电和稳定默认状态、两组 OE、9 路输出与 QEPA 一路反馈的空载静态检查。测试对象、条件和实测值见[首板空载静态测试记录](writing/interface_board_static_test_record.md)。厂装范围和 J1 设计选型见[装配说明](../hardware/v0.1/pcba/)。

## 剩余验证

- **装配与线束**。自购 J1 的精确型号和带键情况待确认。现有记录未列护框/有效针长/止挡及支撑尺寸、完整 40 针同号通断和逐相邻异网检查。J2 到 MBDL4 的安装与 26 芯直通线通断也待核对。原生 BRD 的板外方向、两子板间距及端子映射已有设计记录。[设计审查清单](review_checklist.md) · [叠合图](../hardware/v0.1/review/assembly_overlay.png)
- **反馈**。QEPB、QEPZ、ERRI、ERRU 已观察到默认低，外部高电平待逐路验证。根据实际 AQM 编码器位移分辨率、解码倍率和最大线速度核对边沿间隔，再验证动态计数和线缆负载下的反馈波形。
- **PWM 与负载**。待核对 MBDL4 带载高低电平、光耦输入电流、动态 PWM、互补和死区，以及 `PWM_EN` 禁止和驱动板原有故障关断。电机运动另行验收。
- **控制与保护**。待在真实驱动器上验证继电器、驱动允许、故障锁存与 `F_Reset` 清除。初始保持 `PWM_EN=0`、`RELCON=0`、`ENCON=0`，预置 `F_Reset=1` 后才启用 `CTRL_EN`。清故障和 PWM 再放行独立，详见[电路与初始化](schematic_v0.1.md#初始化与供电关系)。
- **上下电瞬态**。核心 VCCO 独立掉电而 J16 电源仍在时，OE 瞬态及 FPGA 引脚注入待测。现有首板记录覆盖稳定读数。`CTRL_EN` 为软件使能。
