# 当前关键电气问题

两轮独立只读审查均认为 PWM 输入电流保证条件尚未闭合，计算与原板共 CATH 约束见[总原理图说明](schematic_v0.1.md)。原生 ERC 结果单独记录。

后续需确定一个设计方向。

- 将 MBDL4 六路输入阻值及共 CATH 下拉回路调整纳入设计。
- 保持 MBDL4 电路固定，取得厂家规定的输入电压、电流、温区及 CATH 负载包络，再完成输出级和供电设计。

实际编码器 PPR 与最高转速尚未给出。反馈使用条件已在图内标为每路不超过 100 kHz、A/B 相邻边沿至少 2 µs、A 侧总负载不超过 50 pF。后续控制集成应确认所用编码器符合这些条件。

机械资料给出两块开发板整板尺寸及接口脚距，未给本子板板框、J16 距边、叠合净高或散热器禁布尺寸。后续板框可作为本板设计尺寸标注，连接器叠合仍需按实际端子坐标检查。
