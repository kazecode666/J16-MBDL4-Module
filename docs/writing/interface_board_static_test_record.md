# J16—MBDL4 V0.3首板空载静态测试记录

整理日期：2026-11-20。目的：为论文两节审阅提供真实试验依据，不是后续带功率联调的操作授权。

## 1. 记录来源与试验条件

以下数值来自用户在2026年11月19—20日本轮对话中逐项提交的万用表读数及VIO截图，按测试阶段转录。整理者没有远程操作仪器，也没有自动采样文件、仪表型号/精度或多板统计；缺少的数值不补写。不同阶段的电压不是同时采样结果，不据此计算精确传输增益、效率或测量误差。

接口板J1已经自行焊接并实际插入AXU5EV的J16。测试工程来自[AXU5EV PR #49](https://github.com/kazecode666/AXU5EV/pull/49)，使用VIO静态控制、约50 MHz的PS→PL时钟和五路两级同步反馈。MBDL4数字口、功率母线与电机均未接入本次测试链路。STM32板仅在QEPA试验中提供5 V测试高电平，与接口板共地；其5 V未并接到接口板供电轨。

## 3. U1：OE与六路PWM

### 3.1 Q1使能控制

| PWM_EN状态 | R13.2：OE_PWM_N | R19.2：OE_CTRL_N |
|---|---:|---:|
| 0，初始 | 3.304 V | 3.302 V |
| 1 | 0.019 V | 3.300 V |
| 恢复0 | 3.303 V | 3.300 V |

### 3.2 输出与禁止

| 条件 | 测点/报告 | 实测 |
|---|---|---|
| PWM_EN=1、PWM1=1 | J2.1 | 5.092 V |
| 同上，其余PWM=0 | J2.2～6 | 各路0 V |
| 同上 | R13.2、R19.2 | 0.020 V、3.300 V |
| 保持PWM1=1，令PWM_EN=0 | J2.1、R13.2 | 0.002 V、3.303 V |
| PWM2～PWM6逐路0→1→0 | 用户报告“step2测试都没问题” | 逐路确认正常；没有单独电压数值 |
| 全部PWM归零、关闭PWM_EN | 用户报告“step3也没问题” | 归零及禁止恢复正常 |

结论：六路PWM空载静态传输和PWM组使能/禁止符合本轮预期。高输入下关闭OE的量化记录针对PWM1；不要写成六路逐一都有同样的禁止电压实测值。

## 4. U2：控制输出与CTRL使能

CTRL_EN=1、PWM_EN=0、RELCON=0、ENCON=0、F_Reset=1时：

| 测点 | 实测 |
|---|---:|
| R19.2 | 0.030 V |
| R13.2 | 3.303 V |
| J2.7 | 0 V |
| J2.8 | 0 V |
| J2.9 | 5.091 V |

保持CTRL_EN=1，逐路切换：

| 信号 | 实测电压变化 |
|---|---|
| RELCON，J2.7 | 0 → 5.093 V → 0 |
| ENCON，J2.8 | 0 → 5.093 V → 0 |
| F_Reset，J2.9 | 5.095 V → 0 → 5.095 V |

结论：三路控制电平传输通过；CTRL组使能时PWM组仍禁止。没有驱动板参与，因此没有验证继电器吸合、实际驱动允许或故障锁存复位。

## 5. U3：QEPA的高、低电平与FPGA接收

### 5.1 默认低与禁止状态观察

用户确认，CTRL_EN=1且未施加外部反馈信号时，五个VIO反馈输入均为0。

方向导通检查后，用户先进行接口板独立供电/禁止输出检查：QEPA_B=5.022 V，QEPA_BUF=0 V。随后完整接回AXU5EV并施加STM32的5 V测试信号，CTRL_EN=0时R19.2约3.3 V；用户观察到QEPA_sync先为1后为0，以及表笔跨接R30时出现0/1变化。

这些观察不构成高阻漏电流测量。探针接入可能影响浮空节点，但本轮未分离具体耦合路径，不能写成已证实“万用表注入某一大小电流导致跳变”。跨接33 Ω的压降与两端各自对地的电压是不同测量，最终有效输出数据采用后者。

### 5.2 有效传输

最终接线：STM32 5 V→J2.21、GND→J2.25；接口板完整接入J16，由AXU5EV供电。保持PWM_EN=0、RELCON=0、ENCON=0、F_Reset=1。

| 条件 | R19.2 | R30靠U3端QEPA_BUF对GND | R30靠FPGA端QEPA_A对GND | QEPA_sync |
|---|---|---:|---:|---|
| STM32供电，CTRL_EN=1 | 约0 V | 3.306 V | 约3.306 V | 稳定1 |
| 关闭STM32电源，CTRL_EN仍为1 | 用户未另报数值 | 0 V | 0 V | 恢复0 |

低电平恢复时保持U3使能，故不是靠关闭OE制造逻辑0。用户未在这个最终低电平步骤单独报出J2.21数值，不补填；5.022 V来自此前B侧测试，不能伪装成与3.306 V同步采样的精密测量组。

结论：QEPA一路“J2→U3→R30→J1/J16→FPGA同步输入及VIO”空载静态传输通过。R30两端稳定高电平均约3.306 V，同时VIO稳定为1；撤去外部输入后两端与VIO均回低。该结论不包含瞬态过冲或长期可靠性。
