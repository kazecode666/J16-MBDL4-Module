## 当前工艺待审

1. 路线B的厂装部分全部位于顶面，经济型公开能力为单面贴片加插件、最小10×10mm，工艺边及Mark为可选。60×55mm符合该公开尺寸范围，可作为经济型能力候选，接单与J2插件焊接由厂家审核。[工艺能力](https://www.jlc-smt.com/vtechnology)、[尺寸及类型说明](https://www.jlc.com/portal/server_guide_26.html)
2. C10/C11与J1周边所有49件SMT已按≥5mm目标测量，最小值5.22838mm。顶层66个0603原生U形焊膏开窗的钢网厚度、锡量、开口及焊接曲线仍需工厂工艺审核。J2网页列Wave Soldering，国际API列manualWeld，本单实际后焊方式由厂家确定。[插件治具指南](https://www.jlc.com/portal/q7i49377.html)、[J2装配库](https://jlcpcb.com/partdetail/hanxia-HX_JN2_54_2x13P_ZZ_H89/C42455950)
3. 当前需取得本设计订单级50件物料匹配、安装面/旋转预览、J2代焊及经济型工艺受理。若厂家选择工艺拼板，应按其工程稿同步位号数量、坐标偏移和制造数据。用户自购J1需在断电试配后拆离开发板焊接，并完成40针同号通断和相邻异网短路检查。[J1后焊说明](j1_selection.md)

建议工厂审核采用双层FR4、1.6mm、1oz、绿油白字及无铅喷锡基线，钢网和损耗数量随订单审核确定。当前厂家装配目标为50件，J1后焊由用户完成，订单受理状态为待审核。
