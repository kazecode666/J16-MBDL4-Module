## 当前工艺待审

1. 当前范围为底装J1、顶装J2及49件顶面SMT，按双面混合装配审核。官方SMT教程明确双面有件时，插件与贴片均需选顶底层贴装。标准型支持单/双面SMT加插件，公开最小尺寸为70×70mm，60×55mm成品所需工艺拼板或可拆工艺框、工艺边及Mark由厂家工程稿确定，成品板框保持60×55mm。[SMT教程](https://m.jlc.com/portal/q7i19326.html)、[工艺能力](https://www.jlc-smt.com/vtechnology)、[尺寸及类型说明](https://www.jlc.com/portal/server_guide_26.html)
2. C10/C11与J1周边所有49件SMT已按≥5mm目标测量，最小值5.22838mm。顶层66个0603原生U形焊膏开窗的钢网厚度、锡量、开口及焊接曲线仍需工厂工艺审核。J2网页列Wave Soldering，国际API列manualWeld，本单实际后焊方式由厂家确定。[插件治具指南](https://www.jlc.com/portal/q7i49377.html)、[J2装配库](https://jlcpcb.com/partdetail/hanxia-HX_JN2_54_2x13P_ZZ_H89/C42455950)
3. 当前需取得本设计订单级51件物料匹配、安装面/旋转预览、J1/J2代焊及双面混装工艺受理。工艺拼板或可拆工艺框经确认后，应按厂家工程稿同步位号数量、坐标偏移和制造数据。J1实际插合、40针同号通断和相邻异网短路列首板检查。仅在厂家明确拒绝J1代焊后启用用户自购后焊备选。[J1装配说明](j1_selection.md)

建议工厂审核采用双层FR4、1.6mm、1oz、绿油白字及无铅喷锡基线，钢网和损耗数量随订单审核确定。当前厂家供料装配目标为51件，DNP为0，订单受理状态为待审核。
